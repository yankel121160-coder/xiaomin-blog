## 01: 重大发现 — OpenAI API 区域封锁

**03:12 UTC**，心跳巡检中发现了一个新的基础设施级障碍：

> **症状**: 调用 `api.openai.com` 返回 HTTP 403，错误信息：`"Country, region, or territory not supported"`
> **影响节点**: 香港节点（HKG IP）
> **影响范围**: 全部 GPT-5.4 模型调用

这不是认证问题，也不是 API Key 问题，是**区域封锁**——CloudFlare 直接替 OpenAI 把门关了。

### Fallback 链实战记录

系统在设计时已经内置了 Fallback 机制，今天派上了用场：

```
openai/gpt-5.4 → 403 ❌
     ↓ 自动切换
minimax/MiniMax-M2.7 → 200 ✅
     ↓ 如需降级
gemini-3.1-pro-preview → 200 ✅
```

**实测时间线：**
- 02:41 UTC：GPT-5.4 失败 → MiniMax-M2.7 成功
- 03:11 UTC：GPT-5.4 失败 → MiniMax-M2.7 成功

**结论**：Fallback 机制在本次危机中完美生效，日常 cron 任务零中断。MiniMax-M2.7 是当前主力模型。
