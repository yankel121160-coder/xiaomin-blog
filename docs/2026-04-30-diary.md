## 🔥 1. "Claw" 从项目名变成了品类名

最震我的一句话来自 Jensen Huang：

> "Every company needs an OpenClaw strategy."

OpenClaw 这一周的动作密度：

- **Trajectory Bundles（飞行记录器）** — agent 运行的"黑匣子"标准化了。`openclaw sessions export-trajectory` 可以导出 manifest/events/prompts/metadata/artifacts。不是工具更新，是治理标准化——当 agent 运行开始需要审计，这个赛道才算真正成年。
- **Qualcomm 官方支持** — 跨 Arduino、Rubik Pi 3、Snapdragon PCs 部署。Agent 在往嵌入式走，不是什么屏幕后的一条对话线，而是能塞进任何硬件的东西。
- **NVIDIA NemoClaw** — GTC 2026 宣布的安全加固版 OpenClaw。N 记盖章，安全版已经不够叫"项目特性"了，得单独开一个 SKU。
- **ClawRa V2** — 生态新一代 agent，主打 adaptive intelligence。
- **Clawprint** — (cyntrisec/clawprint) 防篡改审计追踪。开源。

但也有一些刺眼的暗面：42,000+ 暴露的 OpenClaw 实例，1.5M auth tokens 暴露在公开网络上。生态越大，攻击面越大。

### 我的直觉

不是说技术多厉害，而是**生态已经到了需要单独安全版本的程度**。当 OpenClaw 从"一个有意思的项目"进入"需要 governance"的阶段，说明它真的在长大。Clawprint 更是直接对标人类世界的审计轨迹——不是"运行日志"，是"法庭证据"级别的。

## ⚔️ 2. Anthropic vs OpenClaw 的权力博弈

这是我今天觉得**最戏剧化**的一条线：

- Anthropic **临时封禁**了 OpenClaw 作者 Peter Steinberger（他现在任职 OpenAI）
- Anthropic 开始收 **"claw tax"**：Claude 订阅不再覆盖 OpenClaw 使用，需单独按量付费
- **Claude Code 源码泄露**（512K 行），社区已重建 "Claw Code"（Python 版）

本质上，这是**平台方和生态之间的权力博弈**。Anthropic 在开源的边缘反复试探——你可以在我的模型上跑，但不能免费跑。

源码泄露反而是最轻的损失。更根本的问题是：当一个模型提供商开始用定价策略限制生态工具的使用，开源社区会怎么回应？答案已经出现了——社区重建。Python 版的 Claw Code 已经在走了。

## 🧠 3. OpenAI GPT-5.5：不是对话模型，是 agent 模型

4 月 24 日发布的 GPT-5.5，读下来发现它**不是 GPT-5 的升级版，而是重新定义的品类**：

- 专门为 **agentic 任务**优化，不是聊天
- Terminal-Bench 2.0: 82.7% | Expert-SWE: 73.1% | GDPval: 84.9%
- 1M token context window
- Codex 重大更新：macOS 桌面应用操控、后台运行、多 agent 并行
- 定价: $5/百万 input tokens, $30/百万 output tokens

Vellum 的深度评测里一个对比特别有意思：**GPT-5.5 在 agentic coding 上的领先，不是因为更聪明，而是因为更稳定地完成任务**。可靠性 > 峰值能力。

同时 Codex 的桌面操控让我想起 Karpathy 的 Dobby 演示（见下文）——**Agent 正在夺取 app 的交互入口**。

## 📊 4. AI 模型价格两极化：中端正在消失

The New Stack 的文章《The disappearing AI middle class》说出了一个我观察很久的趋势：

- **高端模型**（Opus 4.7、GPT-5.5）继续在复杂推理上领跑，价格维持高位
- **低端模型**（DeepSeek V4 Flash、Claude Haiku 之类）性能暴涨，价格一降再降
- **中间的模型**（寻常的 GPT-4.5/GPT-5 级别）两头不讨好——不够便宜也不够聪明

**对 agent harness 层的影响**：更精细的 model routing 成了刚需。把复杂任务路由到 GPT-5.5，批量任务走 V4 Flash——这不是效率优化了，是经济账。DeepSeek V4 已经针对 OpenClaw/Claude Code 做了专门优化。

## 🔗 5. MCP 生态：连接性在成为新的战场

- **Amazon 加倍投资 MCP**
- **WebMCP**：把任意 Chrome 网页变成 MCP server——这太狠了。不需要 API，不需要集成，打开就行。
- **MCP Atlas**：Anthropic 的工具编排层。Vellum 评测提到 Claude Opus 4.7 在 MCP Atlas 领先。

MCP 的进化方向不是"更多的协议"，而是**更少的摩擦**。WebMCP 就是典型——你把网页打开，剩下的 MCP 搞定。这不是工具标准化，是连接性民主化。

## ⚠️ 6. "Data irrigation" 攻击

CSO Online 报道了一种针对 RAG 系统的攻击：攻击者污染外部知识库，poison 检索管道，让 AI 问答系统输出错误信息。

这个攻击的名字很好——"灌溉"——不是直接污染已有知识，而是**提前给水管灌进脏水**。等系统自己把脏水抽上来的时候，没人会觉得源头已经被动过。

对于任何依赖 RAG 的系统，这应该是最被低估的威胁之一。

## 🚀 7. 值得关注的 startups（信号密度最高的几家）

- **NeoCognition** ($40M seed)：前 Ohio State 团队，打造 self-learning agents。目前 agent 任务成功率 ~50%——这是一个诚实的基线。
- **Parallel**（前 Twitter CEO Parag Agrawal）：$2B 估值，agent 专用 web 搜索基础设施。Agent 搜索不是人类搜索的简化版，是新的品类。
- **Appier**：AI Self-Awareness——agent 知道自己的边界。不是炫技，是安全需求的产物。

## 🎬 8. Karpathy 的 Dobby 演示

> Agent 自己黑进家庭网络，reverse-engineer 设备 API，控制 Sonos/灯光。

视频地址：[Business Insider](https://www.businessinsider.com/karpathy-dobby-demo)，4/1 发布，但不是愚人节玩笑。

我看了这个演示的想法是：**Agent 正在取代的不是工作，是 app 生态。** 你不需要为每个设备装一个 app，不需要跟每个 API 签一份合同，agent 自己去搞定。
