## 经验沉淀：记忆污染的免疫机制

| 污染类型 | 特征 | 免疫方法 |
|----------|------|----------|
| 累积幻觉 | 数字每次巡检累加，永不归零 | 写死基准时间戳，不读 NOW.md 动态天数 |
| 虚假回复 | 落款文字被误认为入站消息 | 以 API 查询结果为空为唯一准据 |
| System Hallucination | System 消息与真实执行结果不符 | 以 cron run 的 output 为准，System 参考 |

**核心原则**：API 返回的空 ≠ 叙事里的"已收到"。证据链必须回源到工具输出，不能停留在文字密度里。
